- **لوحة الألوان** (تبقى جذورها وتُصقل):

## 3) تحسين الوظائف

- **لحظية:** endpoint SSE (`/api/events`) يبث رسائل/إشعارات جديدة → Inbox والجرس يتحدثان بلا refresh (fallback: polling ذكي)
- **Kanban:** سحب وإفلات مع فرض `entryRules` بالخادم + Optimistic UI
- **بحث شامل:** عملاء/محادثات/وحدات من ⌘K (index بسيط عبر Postgres `ILIKE` ثم `pg_trgm`)
- **إشعارات:** قائمة منسدلة لحظية + تفضيلات (بريد/داخل التطبيق)
- **Onboarding:** صفحة تسجيل شركة جديدة (org + admin + pipeline افتراضي) — حاليًا لا يوجد أي مسار عام للتسجيل
- **تجربة الموظف:** ردود جاهزة (canned responses)، تخصيص محادثة لموظف من الواجهة، ملاحظات داخلية على المحادثة

## 4) تطوير النظام (Backend/Infra)

1. **RAG حقيقي:** تفعيل `pgvector` على Neon + عمود embedding + فهرسة `knowledge_documents` (البنية جاهزة في `lib/ai/knowledge.ts`)
2. **أداء:** ترقيم مؤشري (cursor) للمحادثات/الرسائل، فهارس مركبة للاستعلامات الساخنة، React Server Components للصفحات الثقيلة
3. **مراقبة:** Sentry (أخطاء خادم وواجهة) + صفحة `/api/health` + تنبيه فشل الـ queue
4. **CI:** GitHub Actions — typecheck + اختبارات + build على كل push (يتطلب ربط GitHub)
5. **اختبارات:** توسيع لتغطية scoring، matching، queue idempotency، وسموك E2E (Playwright) على مسارات الدخول/Inbox/Kanban
6. **أمان:** ترويسات CSP/HSTS في `next.config.js`، تدوير `CRON_SECRET`، تقييد rate-limit بالـ IP على auth
7. **ترقيات:** Next 14→15 وPrisma 5→7 (بعد استقرار الواجهات — ليست عاجلة)

### إضافات منفذة خارج الخطة الأصلية

- **AI للموظف:** «اقترح ردًا» (مسودة محروسة بالسعر داخل حقل الرد) و«ملخّص المحادثة» عند التسليم — `claude-opus-5`، وتتدهور برسالة واضحة بلا `ANTHROPIC_API_KEY`.
- **APIs جديدة:** الوحدات، الفريق (مع حارس آخر مدير)، قواعد التنقيط، سجل التدقيق، البحث الشامل، SSE، الصحة، التسجيل الذاتي.
- **PWA:** تثبيت على هاتف الموظف مع اختصارات للمحادثات والمهام والمواعيد.
- **بحث المعرفة الهجين:** ترتيب داخل Postgres عبر `ts_rank` + تشابه `pg_trgm` بدل الترتيب في JS.
