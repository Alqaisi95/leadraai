# حزمة Meta App Review — قائمة التحقق (R3.1)

**ابدأ اليوم — هذا المسار الحرج الزمني الوحيد بالمشروع (2–6 أسابيع).**

## قبل التقديم
- [ ] إنشاء Meta App من developers.facebook.com (نوع Business)
- [ ] بدء **Business Verification** فوراً (وثائق الشركة الرسمية — الأطول زمنياً)
- [ ] نشر الصفحات على النطاق الفعلي (روابط مطلوبة بالتقديم):
  - [ ] `/privacy` سياسة الخصوصية
  - [ ] `/terms` شروط الاستخدام
  - [ ] `/data-deletion` تعليمات حذف البيانات + Callback URL
- [ ] حساب Instagram مهني تجريبي مرتبط بصفحة Facebook تجريبية
- [ ] حساب مستخدم تجريبي للمراجع بصلاحيات كاملة على بيئة Staging

## الصلاحيات المطلوبة (تحقق من الأسماء الحالية بوثائق Meta — تتغير)
| الصلاحية | الاستخدام المعلن للمراجع |
|---|---|
| instagram_basic | قراءة معلومات الحساب المهني المرتبط |
| instagram_manage_messages | استقبال رسائل العملاء والرد عليها من لوحة موحدة |
| pages_manage_metadata | الاشتراك بـ Webhooks الرسائل |
| pages_show_list | عرض الصفحات لاختيار الحساب أثناء الربط |
| business_management | ربط أصول Business Manager |

## مواد التقديم لكل صلاحية
- [ ] فيديو Screencast (بدون مونتاج مبالغ): الدخول ← ربط الحساب عبر OAuth ← وصول رسالة تجريبية ← ظهورها بالـ Inbox ← رد الموظف ← وصول الرد للعميل
- [ ] خطوات نصية مرقمة للمراجع (بالإنجليزية) لكل صلاحية
- [ ] شرح جملة واحدة: "Leadra AI is a CRM for real-estate companies to manage their own Instagram customer conversations"

## أخطاء رفض شائعة — تجنبها
- فيديو لا يُظهر الصلاحية الفعلية قيد الاستخدام
- بيئة اختبار معطلة وقت المراجعة (المراجع يجرب بنفسه!)
- روابط خصوصية تعيد 404 أو صفحة عامة
- طلب صلاحيات لا يستخدمها المنتج فعلياً

## بعد الموافقة
- [ ] التحويل من Development إلى Live Mode
- [ ] Advanced Access للصلاحيات المعتمدة
- [ ] إعادة اختبار OAuth وWebhooks على الإنتاج
